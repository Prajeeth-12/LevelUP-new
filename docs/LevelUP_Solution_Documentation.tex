\section{Executive Summary \& Problem Statement}

\textbf{LevelUP} is an AI-powered personal career operating system and autonomous learning companion engineered to bridge the modern software developer skill gap. Instead of overwhelming learners with static course catalogs or rigid checklists, LevelUP pairs each engineer with an active, multimodal AI mentor that dynamically benchmarks their skills against industry job descriptions, balances weekly study bandwidth, schedules Kanban sprints, and provides turn-by-turn conversational tutoring.

\subsection{The Three Core Engineering Challenges}
\begin{enumerate}[leftmargin=1.5em]
    \item \textbf{Skill Overwhelm \& Fragmentation:} Learners juggle scattered resources---tutorials, GitHub repositories, Kanban boards, and interview questions---without a centralized intelligence layer connecting them.
    \item \textbf{Cognitive Fatigue \& Backlog Clutter:} Traditional task boards accumulate hundreds of unprioritized items, leading to burnout rather than focused execution.
    \item \textbf{Passive vs. Active Mastery:} Reading documentation without hands-on architecture verification or spoken interview practice creates an illusion of competence.
\end{enumerate}

\subsection{The LevelUP Architecture Solution}
LevelUP unifies career roadmap synthesis, daily task execution, and real-time AI mentorship into a synchronized full-stack architecture:
\begin{itemize}[leftmargin=1.5em]
    \item \textbf{MiniMax-M3 High-Context Intelligence:} Deep reasoning model capable of processing complex architectural prompts, user skills, and active roadmaps.
    \item \textbf{1-Click Kanban Smart Auto-Scheduler:} Dynamically organizes tasks into daily focus sprints based on user study bandwidth (e.g., 12h/week).
    \item \textbf{Voice-First 1-on-1 AI Tutor:} Spoken technical mock interviews and conceptual deep dives via Web Speech APIs.
    \item \textbf{Multimodal Vision \& GitHub Inspector:} Inspects whiteboard diagrams, system schemas, and live GitHub repositories.
    \item \textbf{Human-in-the-Loop Safety Guardrails:} All AI-suggested task additions or skill updates require explicit user approval.
\end{itemize}

\section{Local Setup, Execution \& Deployment Guide}

\subsection{Step 1: Backend Setup (FastAPI)}
\begin{enumerate}[leftmargin=1.5em]
    \item Navigate to the backend directory: \texttt{cd backend}
    \item Create and activate a virtual environment:
    \begin{itemize}
        \item Windows: \texttt{python -m venv venv} \textbar\ \texttt{.\\venv\\Scripts\\activate}
        \item macOS/Linux: \texttt{python3 -m venv venv} \textbar\ \texttt{source venv/bin/activate}
    \end{itemize}
    \item Install dependencies: \texttt{pip install -r requirements.txt}
    \item Configure \texttt{backend/.env}:
    \begin{itemize}
        \item \texttt{MINIMAX\_API\_KEY=<your-key>}
        \item \texttt{MINIMAX\_BASE\_URL=https://api.gmi-serving.com/v1}
        \item \texttt{MINIMAX\_MODEL=MiniMaxAI/MiniMax-M3}
    \end{itemize}
    \item Start the backend: \texttt{python -m uvicorn app.main:app --port 8000 --reload}
\end{enumerate}

\subsection{Step 2: Frontend Setup (React + Vite)}
\begin{enumerate}[leftmargin=1.5em]
    \item Navigate to frontend directory: \texttt{cd frontend}
    \item Install dependencies: \texttt{npm install}
    \item Start development server: \texttt{npm run dev}
    \item Open in browser: \href{http://localhost:3000}{http://localhost:3000}
\end{enumerate}
