\section{Executive Summary \& Value Proposition}

\textbf{LevelUP} is an AI-powered personal career operating system and autonomous learning assistant built to solve the modern developer skill gap. Instead of overwhelming learners with static course catalogs or rigid checklists, LevelUP pairs each user with a proactive, multimodal AI mentor that dynamically benchmarks their existing resume against real-world job descriptions, schedules balanced Kanban sprints, and engages in voice-first 1-on-1 tutoring.

\begin{figure}[H]
    \centering
    \includegraphics[width=0.92\textwidth]{docs/figures/dashboard_roadmaps.png}
    \caption{LevelUP Core Dashboard with Cycle Stats, Roadmap Navigator, and Active Milestones.}
\end{figure}

\subsection{Key Value Pillars}
\begin{itemize}[leftmargin=1.5em]
    \item \textbf{Proactive Autonomous Organization:} The AI does not merely answer questions; it analyzes weekly cognitive bandwidth (e.g., 12h/week) and organizes Kanban tasks into balanced daily sprints.
    \item \textbf{Voice-First 1-on-1 Tutoring:} Learners can practice technical interview questions, DSA problems, and architectural trade-offs using bidirectional spoken audio.
    \item \textbf{Multimodal Vision \& GitHub Inspector:} Users can drag-and-drop architecture sketches or paste GitHub links to extract architectural readiness and identify missing best practices.
    \item \textbf{Human-in-the-Loop Safety:} The AI generates interactive \textit{Proposed Workspace Action Cards} for all task, skill, and roadmap modifications, ensuring the learner maintains total authority before committing changes to their database.
\end{itemize}

\section{Core AI Superpowers \& Capabilities}

\subsection{1. Voice-First 1-on-1 AI Tutor}
LevelUP enables hands-free technical mentorship:
\begin{itemize}[leftmargin=1.5em]
    \item \textbf{Live Microphone Recording:} Uses real-time speech recognition with animated waveform indicators.
    \item \textbf{Turn-by-Turn Audio Synthesis:} Answers are vocalized in natural tone and cadence, allowing audio-guided study during coding.
    \item \textbf{Audio Controls:} Instant mute/unmute toggle in the header and stop buttons for fluid conversation management.
\end{itemize}

\subsection{2. 1-Click Kanban Smart Auto-Scheduler}
Overcoming task fatigue and backlog clutter:
\begin{itemize}[leftmargin=1.5em]
    \item Evaluates all tasks across \textit{To Do}, \textit{Current}, and \textit{Past} columns.
    \item Automatically balances weekly study bandwidth (4h--40h) to isolate 2--4 high-leverage tasks for today's active sprint.
    \item Outputs a pedagogical rationale and presents an interactive checklist for user approval before applying changes.
\end{itemize}

\section{Local Setup \& Execution Guide}

Follow these straightforward steps to run the complete LevelUP platform locally:

\subsection{Step 1: Prerequisites Check}
\begin{itemize}[label=$\square$,leftmargin=1.5em]
    \item Node.js (v18.0 or higher) installed (\texttt{node -v})
    \item Python (v3.10 or higher) installed (\texttt{python --version})
    \item Git installed (\texttt{git --version})
\end{itemize}

\subsection{Step 2: Backend Setup (FastAPI)}
\begin{itemize}[label=$\square$,leftmargin=1.5em]
    \item Navigate to the backend directory: \texttt{cd backend}
    \item Create a virtual environment: \texttt{python -m venv venv}
    \item Activate the virtual environment:
    \begin{itemize}[label=$\triangleright$]
        \item Windows: \texttt{.\textbackslash venv\textbackslash Scripts\textbackslash activate}
        \item macOS/Linux: \texttt{source venv/bin/activate}
    \end{itemize}
    \item Install required packages: \texttt{pip install -r requirements.txt}
    \item Ensure \texttt{backend/.env} contains the MiniMax API key and endpoint configuration.
    \item Launch the backend server: \texttt{python -m uvicorn app.main:app --port 8000 --reload}
    \item Verify Swagger API docs at: \href{http://localhost:8000/docs}{http://localhost:8000/docs}
\end{itemize}

\subsection{Step 3: Frontend Setup (React + Vite)}
\begin{itemize}[label=$\square$,leftmargin=1.5em]
    \item In a new terminal, navigate to the frontend directory: \texttt{cd frontend}
    \item Install dependencies: \texttt{npm install}
    \item Start the development server: \texttt{npm run dev}
    \item Open your browser at: \href{http://localhost:3000}{http://localhost:3000}
\end{itemize}

\subsection{Step 4: Live Verification}
\begin{itemize}[label=$\square$,leftmargin=1.5em]
    \item Click the AI Chat Assistant button to test MiniMax-M3 LLM inference.
    \item Test voice input with the microphone icon and turn on voice audio toggle.
    \item Visit the Tasks page and click \textbf{"AI Auto-Schedule"} to test sprint balancing.
    \item Test Skill Gap Analyzer with a sample Job Description.
\end{itemize}
